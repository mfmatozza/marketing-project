# Quotes: LG laundry, 1-2 star reviews

These are verbatim excerpts. Trimmed parts are marked "...", and spelling is left as written. Each review is tagged with the issue it is listed under. The notebook 04 assert checks this.
Cite them anonymously on slides and in the report, e.g. "LG washer review, 1 star, 2018". The dataset licence is non-commercial teaching only, so don't post them publicly.
